Backend-Agnostic Sparse Attention for Fast High-Resolution Visual Generation

BASA keeps sparse attention regular enough for standard backends while restoring cross-window and long-range communication for high-resolution image and video generation.

Anonymous Authors

▤ Paper ⌘ Code soon ↗ arXiv soon
Overview

High-resolution sparsity that translates into wall-clock speed

Diffusion Transformers become increasingly expensive as visual token sequences grow. Regular partitioned windows are efficient on existing attention backends, but isolated boundaries can create visible grid-like artifacts. Fine-grained sliding windows restore local continuity, yet their irregular access patterns can leave a large gap between theoretical FLOP reductions and measured speedups.

BASA combines shifted local-window attention, K/V-pooled global memory, and, for video, content-adaptive true-window routing. The sparse student is adapted from the original dense model with a frozen teacher, while inference uses only the sparse model.

The core sparse computation remains regular SDPA-style attention — no customized sparse kernel is required.

Motivation

Regular windows are fast. Irregular windows are expressive. BASA targets both.

The design goal is to preserve efficient, backend-friendly execution while enabling information to cross partition boundaries and reach long-range context.

Method

A drop-in sparse attention processor for image and video DiTs

BASA replaces only visual self-attention. The pre-trained Q/K/V projections, cross-attention, MLPs, and the surrounding generation pipeline remain unchanged.

01

Shifted Window Sparse Attention

Local windows stay non-overlapping and regular, while their spatial offsets vary across layers and denoising steps. Tokens separated by one partition can meet under later partitions.

02

K/V-Pooled Global Memory

Spatially pooled keys and values give every local query window a compressed view of the full latent. For video, pooling is spatial only, retaining temporally resolved context.

03

True-Window Routing

Video queries retrieve a small number of relevant uncompressed spatial windows. Routed regions keep their full temporal extent, restoring selected long-range detail without dense attention.

04

Dense-Teacher Sparse Adaptation

A frozen dense teacher supervises the sparse student through flow matching, prediction matching, and intermediate attention-output alignment. The teacher is removed after adaptation.
